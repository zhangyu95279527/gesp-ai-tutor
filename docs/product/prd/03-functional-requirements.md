# PRD — 03-functional-requirements

功能需求按模块组织。优先级：P0 > P1 > P2；验收要点是该功能的最低可验收标准，详细业务规则见 04-business-rules。

## 1. 账号模块（ACC，P0）

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| FR-ACC-01 | 邮箱验证码注册/登录：输入邮箱 → 收验证码 → 验证即登录，登录态 30 天 | P0 | 验证码 5 分钟内有效；重发间隔 60 秒；连续错误 5 次锁定 10 分钟 |
| FR-ACC-02 | 首次注册收集：昵称、出生年月、所报级别（1–8），级别可随时修改 | P0 | 缺项不可进入主功能；修改级别次日对讲解深度生效 |
| FR-ACC-03 | 年龄分层：不满 14 周岁须勾选"已征得监护人同意"并展示未成年人保护条款 | P0 | 未勾选无法完成注册；勾选记录留痕 |
| FR-ACC-04 | 隐私政策与用户协议展示与同意记录 | P0 | 注册页可见链接；同意版本号留痕 |
| FR-ACC-05 | 其他登录方式（微信扫码等） | 后置 | 本期不实现，仅登记 |
| FR-ACC-06 | 未登录体验模式：未注册用户可直接发起完整讲题会话（含 L1–L3 阶梯引导与变式题检验），每日 1 次体验额度；移动端访客可选用内置示例题（1–8 级各 1 道）一键开始体验，无需上传截图 | P0 | 按设备指纹 + 浏览器标识计数（防多浏览器刷体验）；当日体验额度用尽展示注册墙；体验会话不计入注册用户日限额口径；示例题体验同样计 1 次额度 |
| FR-ACC-07 | 体验转注册引导：体验会话结果页（变式题反馈 + 讲解回顾）内嵌注册引导，文案锚定"注册解锁每日 15 次额度 + 错因诊断 + 错题本" | P0 | 注册完成后当日即按正式额度使用；体验→注册转化率可统计（漏斗：落地页→体验发起→体验完成→注册） |

> 说明：FR-ACC-06/07 为注册策略 O8（先体验后注册）的功能落点，旅程见 02-user-journeys J0；体验额度计数规则见 04-business-rules BR-LMT。

## 2. AI 讲题模块（TUT，P0）

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| FR-TUT-01 | 题目输入（同一粘贴区 Ctrl+V，图文自动识别）：题目文本粘贴（首选，OJ 题面直接复制，零识别误差、推理成本更低）+ 题目截图粘贴（含图片/复杂公式/表格时保真）；文件上传图片；移动端相册选择截图；**不接入相机直拍** | P0 | 文本 ≤10000 字符；图片 ≤10MB；粘贴即传；内容明显无效（文本过短/非题目/截图模糊）有提示 |
| FR-TUT-02 | 题目识别与回显确认：识别题目文本、判定考点与级别，用户可确认或纠正 | P0 | 回显可编辑纠正；确认后才进入讲解（纠正信息用于改进识别） |
| FR-TUT-03 | 可选补充输入：粘贴代码片段、文字描述疑问点 | P0 | 代码 ≤5000 字符 |
| FR-TUT-04 | 阶梯式引导：L1 思路提示 → L2 关键步骤 → L3 完整讲解，逐级手动解锁 | P0 | 默认只出 L1；每次解锁留痕（时间、级别、会话）；L3 才可见完整代码 |
| FR-TUT-05 | 会话内追问：学生可在任意阶梯追问，讲解深度按所报级别适配 | P0 | 追问计入日限额；超纲内容按 04-business-rules 处理 |
| FR-TUT-06 | "听懂了"标记 | P0 | 标记率可统计 |
| FR-TUT-07 | 变式题检验：讲解后推送 1 道同考点变式小题，学生作答，AI 判读正误 | P0 | 记录首次做对率；变式题不计入题库、不作 OJ 判分 |
| FR-TUT-08 | 历史会话列表与回看 | P0 | 按时间倒序；可继续追问（占日限额） |

## 3. 错因诊断模块（DIA，P0）

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| FR-DIA-01 | 三件套上传：题目截图 + OJ 评测结果截图 + 学生代码（粘贴文本或文件）；两个截图上传区均以 PC Ctrl+V 粘贴剪贴板截图为首选输入（OJ 刷题主场在 PC），移动端相册选择备选 | P0 | 三者齐备才可诊断；截图粘贴即贴即传；评测截图识别评测状态（WA/TLE/RE/部分得分） |
| FR-DIA-02 | 识别回显确认（复用 FR-TUT-02） | P0 | 同 FR-TUT-02 |
| FR-DIA-03 | 错因定位输出：六类错因之一 + 定位依据；低置信时明示"推断成分"提示 | P0 | 六类：算法选择/复杂度不足(TLE)/边界条件/运行错误(RE)/格式问题/实现细节 |
| FR-DIA-04 | 引导式修正：复用阶梯引导机制，引导自行修正，L3 解锁后可见修正要点 | P0 | 不直接展示改后完整代码（L3 除外） |
| FR-DIA-05 | 解决状态回填："已解决/未解决"标记，未解决可继续追问 | P0 | 解决率可统计 |

## 4. 真题模考模块（EXA，P1）

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| FR-EXA-01 | 真题套卷列表：按级别组织，标注来源（GESP 历届真题） | P1 | 首批级别段见 00-overview Q1（建议 3–6 级） |
| FR-EXA-02 | 限时模考：1–4 级 120 分钟、5–8 级 180 分钟倒计时，在线 C++ 编辑器作答 | P1 | 语法高亮；倒计时结束自动交卷；断网本地暂存 |
| FR-EXA-03 | 自建评测机判分：按题库测试数据逐题判分，输出得分与评测状态 | P1 | 判分结果与官方样例一致率 100%（抽检） |
| FR-EXA-04 | 逐题讲评入口：从判分结果进入引导式讲解（占日限额） | P1 | 与 TUT/DIA 会话框架复用 |

## 8. 运营支撑（OPS，P0 最小集）

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| FR-OPS-01 | 效果度量埋点：阶梯解锁深度分布、变式题首次做对率、听懂标记率、会话轮次、分享回流、体验转化漏斗（落地页→体验→注册）、限额触顶用户次日留存 | P0 | 核心指标可出日报 |
| FR-OPS-02 | 盲评抽样导出：按抽样规则导出讲解会话供教练盲评 | P0 | 抽样规则见 04-business-rules BR-EVA |
| FR-OPS-03 | AI 内容安全过滤：输入输出内容安全检测与拦截记录 | P0 | 拦截有日志；误拦可申诉入口（邮件） |
| FR-OPS-04 | AI 生成内容显式标识：所有 AI 生成内容展示位（讲解页、诊断结果、变式题、模考讲评、分享卡片图片角标）带"AI 生成"显式标识 | P0 | 依据《人工智能生成合成内容标识办法》（2025-09-01 施行）；标识在展示界面合理位置持续可见，不可被用户关闭；分享卡片导出图片同样带角标 |
