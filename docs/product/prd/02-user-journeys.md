# PRD — 02-user-journeys

五个核心旅程：体验、注册与首次使用（J0）、讲题（J1）、错因诊断（J2）、真题模考（J3）、错题重练（J4）。J1 / J2 为 P0 主旅程，J3 为 P1，J4 为 P2。

## J0 体验、注册与首次使用（P0）

**目标**：让用户先免费体验一次完整讲题、感知价值后再注册，注册本身 3 分钟内完成。（注册策略决议见 00-overview O8）

> 前置说明（O9）：J0 描述的公域漏斗以完成生成式 AI 登记为前置；登记完成前的邀请制内测期，入口简化为"受邀 → 凭邀请码注册（FR-ACC-08）→ 正式使用"，无未登录体验公开入口。

1. 用户从公域内容或投放广告（小红书/公众号等）点击链接，在浏览器打开 Web App 落地页。
2. 落地页展示核心价值（"刷题遇阻，知道错在哪、该怎么想"）与讲题示例，主按钮为"**立即免费体验**"（而非"立即注册"）。
3. 未登录用户直接进入一次完整讲题会话（J1 全流程，含 L1–L3 阶梯引导与变式题检验）——**每日 1 次体验额度**，按设备指纹 + 浏览器标识计数，当日用完则展示注册引导；移动端访客手头无截图时，可选用**内置示例题**（1–8 级各 1 道）一键开始体验，同样计入当日体验额度。
4. 体验会话出结果页（变式题检验反馈 + 讲解回顾）→ 页内引导："注册解锁每日 15 次完整额度 + 错因诊断 + 错题本"。
5. 点击注册 → 邮箱注册：输入邮箱 → 收取验证码 → 验证通过即完成注册并登录（登录态 30 天）。
6. 首次注册引导填写：昵称、**出生年月（年龄声明）**、所报 GESP 级别（1–8，可随时修改）。
   - 年龄声明不满 14 周岁：展示《未成年人个人信息保护条款》，须勾选"已征得监护人同意"方可继续。
7. 进入首页，默认引导继续讲题（J1）或发起错因诊断（J2）。

**异常分支**：验证码未收到 → 重发（60 秒间隔）；邮箱已注册 → 直接登录；体验额度当日已用完且未注册 → 展示注册墙，注册后当日即可按正式额度使用。

## J1 讲题（P0 主旅程）

**触发**：学生做题遇阻（未判错，单纯不会或想不通）。

1. 首页点击"讲题" → 粘贴题目：同一粘贴区 Ctrl+V 直接粘贴——**题目文本（首选：OJ 题面直接复制，零识别误差、成本更低）**或题目截图（含图片/复杂公式/表格的题目用截图保真），粘贴时图文自动识别；也支持文件上传图片；移动端从相册选择截图。
2. 可选项：粘贴自己的代码片段或文字描述"卡在哪"。
3. AI 解析题目（文本输入直接结构化；截图输入先 OCR）→ **解析结果回显**：题目文本、判定考点、判定级别 → 学生确认或纠正。
   - 内容明显无效（文本过短/非题目内容/截图模糊）→ 提示重新输入。
4. 确认后进入阶梯式引导：
   - **L1 思路提示**：只给思考方向，不给步骤。学生可追问、可作答交流。
   - 学生表示"还是不会"或交互陷入停滞 → 可手动解锁 **L2 关键步骤**（解锁行为留痕）。
   - 同理可解锁 **L3 完整讲解**（含完整代码参考，解锁行为留痕）。
5. 讲解结束 → 学生可点"听懂了"（辅助信号）。
6. 系统推送 **1 道同考点变式小题** → 学生作答 → AI 判读 → 记录首次做对率（核心效果度量）。
7. 会话页可生成**分享卡片**（题目考点 + 引导过程摘要，不含完整答案）→ 分享回流。

**关键规则**：讲解深度按学生所报级别控制，不超纲；阶梯解锁规则见 04-business-rules。

## J2 错因诊断（P0 主旅程）

**触发**：学生在洛谷等 OJ 刷题判分后"不得分"或"部分得分"，不知错因。

**主输入方式为 PC Ctrl+V 粘贴**：OJ 刷题主场在 PC 浏览器，学生在 OJ 页面"复制题面文本 / 截图评测结果 → Ctrl+V 粘贴"一步完成上传，全程不离开当前窗口。移动端截图统一走相册选择，不接入相机直拍。

1. 首页点击"错因诊断" → 引导上传三件套（三个上传区均支持 Ctrl+V 直接粘贴剪贴板截图，也支持点击选择文件）：
   - 题目（首选 Ctrl+V 粘贴文本，OJ 题面直接复制；含图片/复杂公式时用截图粘贴；移动端相册选择）；
   - **OJ 评测结果截图**（含评测状态：WA / TLE / RE / 部分得分等；同样首选截图粘贴）；
   - 自己的代码（粘贴文本为主，OJ 代码页可直接复制；也支持上传文件）。
2. AI 识别题目与评测结果 → 回显确认（同 J1 第 3 步）。
3. 确认后 AI 输出**错因定位**：六类之一（算法选择 / 复杂度不足 TLE / 边界条件 / 运行错误 RE / 格式问题 / 实现细节）+ 定位依据说明。
4. 进入引导式修正（复用 J1 阶梯机制）：引导学生自己发现并修正错误，不直接给改后代码（L3 解锁后可见修正要点说明）。
5. 学生回 OJ 重新提交验证 → 可回到会话标记"已解决 / 未解决"；未解决可继续追问（占日限额）。
6. 诊断会话完成后同样触发变式题检验与分享卡片（同 J1 第 6–7 步）。

**已知限制**：P0 阶段平台不掌握 OJ 测试数据，"边界条件 WA"类诊断依赖评测结果截图 + 静态分析推断，结论标注置信提示；P1 自建评测机后升级为动态重跑验证。

## J3 真题模考（P1）

1. 首页进入"模考" → 选择级别（默认所报级别）→ 展示该级别可用真题套卷列表。
2. 开始模考 → 全屏答题界面 + 倒计时（时长对齐真实考试：1–4 级 120 分钟，5–8 级 180 分钟）。
3. 在线编辑器作答（C++，语法高亮）→ 交卷。
4. 平台评测机判分 → 展示得分与逐题评测结果。
5. 每题附"讲评入口" → 进入 J1/J2 引导式讲解流程（占日限额）。
6. 错题自动归集到错题本（J4 数据源）。

## J4 错题重练（P2，最简实现）

1. 错题本自动归集三类来源：模考错题、诊断会话标记的题目、讲题会话中学生主动收藏的题目。
2. 列表按考点/级别筛选，点击可重练（重新作答 → 判分或 AI 判读）。
3. 重练结果对比首次作答，展示进步曲线（最简：正确率对比数字）。
4. 提醒：因 Web App 无订阅消息能力，重练提醒采用站内通知 + 邮件（每周一次汇总，可关闭）。

## 旅程间衔接关系

```
公域内容/投放广告 → J0 落地页 → 免费体验 1 次 → 注册 → J1 讲题 ⇄ J2 诊断 → 分享卡片 → 回流获客
                                                        ↓
                                                  J3 模考（P1）→ 错题归集 → J4 重练（P2）
```

J1 与 J2 共享：识别回显确认、阶梯引导引擎、变式题检验、分享卡片、日限额计数。实现上为同一会话框架的两种入口。
