# PRD — 06-mvp-scope

## 范围总览

| 批次 | 模块 | 上线目标 | 状态 |
|---|---|---|---|
| P0 | 引导式 AI 讲题 + 错因诊断 + 账号 + 分享 + 限额 + 运营支撑最小集 | 2026 年 11 月中下旬（邀请制内测，O9） | 待启动 |
| P1 | 真题限时模考（含自建评测机、题库首批级别段） | 2026 年 12 月上旬 | 待启动 |
| P2 | 错题本（最简实现） | 随 P1 | 可降级 |

## P0 范围（Must）

- 账号：邮箱验证码注册/登录（FR-ACC-01~04）、年龄分层与监护人同意；**未登录体验模式与体验转注册引导（FR-ACC-06/07，注册策略 O8 的核心落点）**；邀请码门控（FR-ACC-08，O9 内测期执行机制）。
- 讲题：题目输入（PC Ctrl+V 粘贴文本/截图首选，文件上传与移动端相册备选）、解析回显确认、阶梯引导（L1/L2/L3）、追问、听懂标记、变式题检验、历史会话（FR-TUT-01~08）。
- 错因诊断：三件套上传（PC 粘贴首选）、六类错因定位、引导式修正、解决状态回填（FR-DIA-01~05）。
- 分享：讲解页分享卡片 + 落地页（FR-SHR-01/02，落地页主按钮"立即免费体验"）。
- 限额：日 15 次 + 用量展示（FR-LMT-01/02）。
- 运营支撑：效果度量埋点、盲评抽样导出、内容安全过滤、AI 生成内容显式标识（FR-OPS-01~04）。
- 合规上线前置（O9）：生成式 AI 登记、ICP 备案、隐私政策法务评审（NFR-CMP）——仅约束**公开上线**（开放注册/投放/公开体验）；邀请制内测不面向公众，不适用此前置。

**P0 诊断依据**：静态代码分析 + 评测结果截图；不依赖自有题库与评测机（题目文本/截图粘贴输入天然无题库依赖）。

## P1 范围（Should）

- 真题模考：套卷列表、限时作答、在线编辑器、自建评测机判分、逐题讲评入口（FR-EXA-01~04）。
- 题库建设：首批级别段真题入库（已定案 3–6 级，2026-10-24 PO 裁决，见 00-overview Q1），测试数据按 O7 方案（公开收集 + 自命边界数据 + 人工抽检校准）。**上线量纲：每级别 ≥ 2 套真题、3–6 级共 ≥ 8 套（含全部测试数据校准完成）方可开放 P1**；建设进度不足时按降级预案收窄级别段，不以凑数降低测试数据质量。
- 诊断升级：自建评测机落地后，错因诊断升级为"静态分析 + 动态重跑验证"。

## P2 范围（Could，可降级）

- 错题本：自动归集、重练入口、筛选、提醒（FR-WBK-01~04）。
- 降级方案：整体降级为"仅自动归集列表 + 查看历史会话"，重练与提醒砍掉；再降级则整模块延后至考后。

## 明确不做（首阶段）

承接 Brief，本期不做：

- 图形化 / Python 语言线；体系化课程。
- 教师端 / 机构端功能；家长端独立功能（引导过程报告为远期付费点候选）。
- 任何付费功能（免费工具先行）。
- 社区 / 社交 / 排行榜。
- 原生 App、微信小程序（O1 已决：Web App 单端）。
- 其他登录方式（微信扫码等，邮箱登录优先，其余后置）。
- 自建社区化题库/UGC 内容。
- 相机直拍上传：练习与认证均为机上场景，题目天然以截图形式存在；移动端统一相册选择截图，不接入相机（消除移动浏览器相机权限兼容成本）。

## 降级与风险预案

| 触发条件 | 预案 |
|---|---|
| 交付时间不足 | P2 按上述方案降级；P1 题库级别段收窄（3–6 级 → 5–6 级，保进阶段核心人群） |
| 种子获客不足（H7 落空） | 降级为邀请制小样本验证，效果结论降权 |
| CCF 授权被拒（O2） | P1 题库切换为考纲自命题 + 考点映射；已上真题 48 小时内下线 |
| 单次推理成本超标（O3） | 回审限额值（下调日限额）或 GA 更换模型；不动免费原则 |
| 生成式 AI 登记暂缓（O9 已决） | **当前默认路径**：邀请制内测（不面向公众，FR-ACC-08 门控）；公开上线顺延至登记完成 |
| 未登录体验被批量刷取 / 体验流量成本失控（O8 附带风险） | 先加人机验证（验证码）抬高刷取成本；仍失控则临时下调体验额度（如每周 1 次）或暂停体验入口，已注册用户使用不受影响 |

## Backlog（本期外候选，考后复盘时排序）

以下来自评审与决策过程，本期明确不做但值得考后重新评估：

- 私域分享优化：微信生态内的分享卡片打开体验与传播链路（O1 Web App 既定前提下的折中增强）。
- 考后桥梁动作：成绩录入、2027-03 考期备考计划衔接、考后留存激活 Campaign（对应成功指标"考后留存意愿 ≥40%"的承接动作）。
- 微信扫码等其他登录方式（FR-ACC-05）。
- 家长端"引导过程报告"（远期付费点候选，数据源为阶梯解锁留痕）。
- 题库扩展：1–2 级、7–8 级真题段（视 P1 首批 3–6 级验证结果）。
- 纸质材料拍照上传：仅当考后复盘出现"纸质讲义/练习册拍照求助"的真实场景证据时再评估（当前以内置示例题覆盖移动端体验冷启动）。
