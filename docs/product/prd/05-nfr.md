# PRD — 05-nfr

仅记录**产品相关**的非功能需求（体验、合规、成本、质量目标）；系统架构、部署、技术选型类 NFR 属 GA 架构基线范围，不在此定义。

## NFR-PERF 性能体验

| 编号 | 需求 | 目标值 |
|---|---|---|
| NFR-PERF-01 | 题目识别 + 首轮讲解：流式输出首字延迟 | P75 ≤ 5 秒 |
| NFR-PERF-02 | 图片上传大小上限 | 10MB，超限前端压缩或提示 |
| NFR-PERF-03 | 页面首屏加载（4G 移动网络） | P75 ≤ 3 秒 |
| NFR-PERF-04 | 模考判分反馈（P1） | 交卷后 ≤ 30 秒出结果 |

## NFR-CMP 合规（上线前置条件）

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-CMP-01 | 生成式 AI 服务备案/登记 | 面向公众提供生成式 AI 服务，P0 上线前完成备案或使用已备案模型的登记流程（《生成式人工智能服务管理暂行办法》）；**G2 通过后立即启动，为关键路径首项**（00-overview Q3） |
| NFR-CMP-02 | 未成年人保护 | 年龄分层 + 监护人同意勾选 + 未成年人个人信息保护条款（见 BR-CMP） |
| NFR-CMP-03 | 隐私政策法务评审 | P0 上线前完成文本评审（00-overview Q2） |
| NFR-CMP-04 | 用户数据境内存储 | 邮箱、学习行为数据存境内；不使用境外模型 API 处理用户数据（影响 GA 模型选型约束） |
| NFR-CMP-05 | 网站 ICP 备案 | Web App 域名上线前完成 |

## NFR-SAFE 内容安全

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-SAFE-01 | AI 输入输出双向内容过滤 | 涉政/涉黄/暴力/欺凌拦截，记录日志（FR-OPS-03） |
| NFR-SAFE-02 | 讲解内容不产出诱导性、攻击性表述 | 纳入盲评"表达与安全"维度 |
| NFR-SAFE-03 | 用户上传图片仅用于当次识别与本人历史回看 | 不对外展示、不进公域内容 |
| NFR-SAFE-04 | AI 生成内容显式标识 | 《人工智能生成合成内容标识办法》（2025-09-01 施行）：所有 AI 生成内容展示位带"AI 生成"显式标识，持续可见、不可关闭；分享卡片导出图片带角标（FR-OPS-04）；文件元数据隐式标识的技术实现移交 GA |

## NFR-USE 可用性

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-USE-01 | 移动优先响应式，PC 为一等场景 | 手机浏览器（微信内置、Safari、Chrome）覆盖公域落地与讲题场景；PC 浏览器覆盖 OJ 刷题伴生的错因诊断主场景（J2），两端均须完整可用 |
| NFR-USE-02 | 粘贴体验（文本/截图） | PC 端粘贴区支持 Ctrl+V 直接粘贴题目文本或剪贴板截图，图文自动识别、即贴即传；移动端统一走相册选择截图，不接入相机直拍（消除移动浏览器相机权限兼容成本） |
| NFR-USE-03 | 落地到开始体验 ≤ 30 秒；注册流程 ≤ 3 分钟 | 未登录用户从落地页一键进入体验会话（J0 旅程目标）；注册流程本身 ≤ 3 分钟完成 |
| NFR-USE-04 | 文案语言 | 简体中文；讲解用词适配中小学生阅读理解水平 |

## NFR-COST 成本纪律

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-COST-01 | 单用户日 AI 请求上限 15 次 | 计数口径见 BR-LMT |
| NFR-COST-02 | 单次 AI 请求平均成本测算与月度总成本预估 | GA 阶段产出测算模型，按 300 注册用户 / 100 活跃用户 + 投放带来的未登录体验流量（每日 1 次/设备）预估月度推理成本，超标需回审 O3 决议 |
| NFR-COST-03 | 图片识别优先复用当次会话上下文 | 避免同会话重复大图推理（技术实现约束，GA 落实） |

## NFR-REL 可靠性与运营窗口

| 编号 | 需求 | 目标值 |
|---|---|---|
| NFR-REL-01 | 冲刺窗口（12-12 至 12-26）服务可用性 | ≥ 99.5% |
| NFR-REL-02 | 核心效果指标日报 | 每日产出：活跃用户、会话数、变式做对率、限额触顶率、**触顶用户次日留存率**（触顶是否造成流失的关键监控，触顶次日留存显著低于整体则回审 O3 限额值）、体验转化漏斗（落地页→体验→注册） |
| NFR-REL-03 | 讲解质量人工抽检 | 上线初期每日抽 10 个会话人工看一遍（R2 缓解），持续至盲评机制稳定 |

## NFR-DATA 数据与度量

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-DATA-01 | 效果度量埋点覆盖金标准指标 | 变式题首次做对率、盲评均分、阶梯解锁分布必须可统计（FR-OPS-01） |
| NFR-DATA-02 | 用户行为数据保留期 | 学习行为数据保留至考后复盘完成（2027-01 后按隐私政策执行） |
