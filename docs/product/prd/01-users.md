# PRD — 01-users

## 首要用户（使用者）

备考 GESP C++ 1–8 级的中小学生。按备考阶段分为两个画像：

### 画像 A：入门段学生（1–4 级）

- 小学高年级至初中，多数在机构或家长安排下开始信奥路径。
- 自制力弱，遇阻容易放弃或转而搜答案；最需要引导式、鼓励式的讲解语气。
- 典型场景：做洛谷入门题单时卡在题意理解或简单实现上。
- 对产品的要求：讲解不超纲（只用该级别考纲内的知识讲）、步骤碎、反馈快。
- 操作特征：练习与认证均在电脑上进行，截图上传需要流程足够简单（低年级学生可由家长协助截图上传）。

### 画像 B：进阶段学生（5–8 级）

- 衔接 CSP-J 的核心群体（7 级 ≥80 分 / 8 级 ≥60 分可免 CSP-J 第一轮），动机最强、刷题量最大。
- 具备独立诊断简单错误的能力，痛点集中在：复杂度估算失误（TLE）、边界条件遗漏（部分得分）、算法选型错误。
- 典型场景：洛谷刷题判分"部分得分"或"不得分"后，看不出错因，需要定位与引导。
- 对产品的要求：错因定位准、讲解可直接进入关键步骤、不啰嗦。
- 操作特征：主要在 PC 浏览器刷 OJ，判分后截图粘贴（Ctrl+V）上传是最顺手的诊断发起方式。
- 是 P0 错因诊断模块最迫切的目标人群。

两段用户共用同一套产品能力，差异通过"所报级别"驱动的讲解深度控制来适配（规则见 04-business-rules）。

## 相关方（非首要用户，本期不建独立功能）

| 角色 | 与产品的关系 | 本期策略 |
|---|---|---|
| 家长 | 关注进步可视化；未来的潜在付费方；未成年人使用的实际授权人 | 注册流程中获取监护人同意（14 岁以下）；讲解页分享卡片让家长可感知学习过程；引导过程报告是远期付费点候选，本期不做 |
| 信息学老师 / 教练 | 潜在背书与传播节点；讲解质量盲评的评分人 | 盲评纳入效果度量流程；不建教师端功能 |

## 首阶段非目标用户

- 图形化 / Python 语言线考生。
- 成人编程学习者。
- 学校 / 机构采购场景（无教师端、无管理后台对外售卖）。

## 用户核心诉求与产品响应映射

| 诉求 | 来源画像 | 产品响应 | 优先级 |
|---|---|---|---|
| 遇阻时获得即时、贴合级别考纲的讲解 | A / B | 引导式 AI 讲题（截图上传，不依赖自有题库） | P0 |
| 判分后知道错在哪、该怎么想 | B 为主 | 错因诊断（评测结果截图 + 代码上传 → 六类错因定位 → 引导修正） | P0 |
| 讲解不直接给答案，能真正学会 | 家长 / 教练视角 | 阶梯式引导（思路提示 → 关键步骤 → 完整讲解）+ 变式题检验 | P0 |
| 结构化真题限时训练 | A / B | 真题模考（限时 + 判分 + 讲评入口） | P1 |
| 错题可回顾、可重练 | A / B | 错题本（自动归集 + 重练入口） | P2 |
