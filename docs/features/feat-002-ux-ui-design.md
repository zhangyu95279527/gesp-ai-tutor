## 1. 范围与非范围

范围内：

- 三个页面：讲题会话页（移动/桌面）、历史会话列表、历史会话回看。
- 输入与识别流：粘贴/上传截图、识别中、识别回显确认与纠正、无效输入、识别失败、考纲外提示。
- 讲题会话流：阶梯 L1→L2→L3 手动逐级解锁、追问、听懂盖章、变式题作答与判读、安全截断、超限（复用 FEAT-005 C1/C2）。
- AI 生成内容角标（PBI-0022）在所有 AI 卡片的挂载。

非范围：

- C1/C2 组件本体的状态机与文案口径：归 FEAT-005 设计，本文仅落实挂载与复用（顶栏槽位、超限内联卡、输入区禁用态）。
- 登录/注册、学段设置、错因诊断（FEAT-003）、学情报告（FEAT-004）页面本身。
- 变式判读错答后的讲解页：复用本会话页阶梯卡，不另设页面。

## 2. 设计语言「讲义纸感 · 循循善诱」

定位：像一张干净讲义纸，克制、可信任；色彩只服务于信息层级，不装饰。印章朱全局仅出现一次语义——「听懂了」盖章时刻，形成记忆点。

### 2.2 字体与圆角

- 标题/讲义感：宋体系 `"Songti SC","STSong","SimSun","Noto Serif SC",serif`（页面标题、印章文字）。
- 正文：黑体系 `"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`。
- 代码/数字：`Consolas,"JetBrains Mono",monospace`（用量数字、伪码、代码）。
- 圆角：卡片 14px，胶囊 999px；发丝线 1px，不用重边框。

### 2.3 图标与动效

- 图标全部内联 SVG（线性 1.8–2.2px 描边），不用 emoji，不依赖图标库 CDN。
- 动效仅两处：识别中 shimmer/打点（过程感）、盖章 stampIn（0.4s 缩放落章，一次仪式）。其余状态静态呈现。

## 3. 用户流

F1 输入识别主流：

```
粘贴/上传截图 → 识别中（骨架+打点） → 识别回显卡（题干/考点/级别，可纠正）
→ 确认 → 生成与检查中（不展示未检查候选）→ L1 思路提示（计 1 次，C1 刷新）
```

F2 阶梯解锁流（BR-GUD 核心）：

```
L1 卡片（禁步骤禁代码） → 点「解锁 L2」（确认消耗 1 次） → L2 伪代码（禁完整代码）
→ 点「解锁 L3」（确认消耗 1 次） → L3 完整讲解（代码+复杂度+拓展视野）
→ 卡底「出道变式题试试」
```

F3 盖章与变式流：

```
任意层级点「听懂了」 → 盖章动画 + 留痕（不计次） → 幂等态「已听懂 · 已盖章」
→ 确认生成（预留 1 次）→ 运行校验通过后显示变式题卡（此时正式计 1 次）
→ 提交首次作答（不再扣次）→ 判读卡；判读失败显示「判读暂不可用，答案已保留」，重试不覆盖首次答案
```

F4 边界流：

```
考纲外：识别回显/会话内持续标注「通用讲解，不针对考级」，L1–L3 照常解锁
超限：C1 归 0 → 输入区禁用 + 消息流末尾 C2 卡 → 引导回看历史
安全截断：待检片段不展示 + 「后续内容未通过检查，已停止生成」提示，照计次数；不得把安全截断说成内容过长
```

F5 历史流：

```
历史列表（时间倒序，阶梯/盖章/变式状态一览） → 回看（只读完整内容，不计次）
→ 继续追问（计当日限额）
```

## 4. 信息架构与页面清单

| 页面 | 路由（规划） | 断点行为 |
|---|---|---|
| 讲题会话页 | `/session` | 移动单列消息流；桌面左栏历史 + 右栏会话（PC 一等场景） |
| 历史列表 | `/history` | 移动全宽列表；桌面并入会话页左栏 |

## 6. 组件状态表

### 6.1 阶梯横条 `.ladder-strip`

| 状态 | 类 | 呈现 |
|---|---|---|
| 未解锁 | `.locked` | 锁图标 + 辅助色，不可点 |
| 当前层 | `.active.lv1/2/3` | 层级色数字圆点 + 层级色标签 |
| 已完成 | `.done` | 对勾圆点 + 墨色标签 |

移动端紧凑（仅标签）；桌面端带 `.sub` 每级说明。

### 6.2 讲解卡 `.msg-ai .card`

卡头固定左 `lvl-chip`（层级色章）右 `ai-badge`（PBI-0022 角标）；追问卡用中性深灰章 `#5A6478`，不占阶梯色。卡底按层级挂不同操作：L1/L2 挂「听懂了」，L3 追加「出道变式题试试」。

### 6.3 解锁卡 `.unlock-card`

虚线边界（未发生的内容不伪装成实体卡）：问题句 + 次级说明 + `btn-unlock` + 消耗预告 `消耗 1 次 · 今日剩余 n → n-1`。429 超限时不渲染解锁卡，走 C2。

### 6.4 印章 `.stamp`

双环朱印 + 宋体「听懂了」+ 当日日期；落章后卡底按钮变幂等态「已听懂 · 已盖章」（灰绿，不可再点）。历史列表缩略为 `stamp-mini` 朱砂标签。印章朱不做任何其他用途。

### 6.5 用量指示器与超限卡

完整状态机见 feat-005-ux-ui-design.md 第 4/5 节；本特性落实：顶栏常驻槽位（移动/桌面均不随滚动隐藏）、n≤3 赭石强调、n=0 时输入区禁用占位「今日次数已用完，明天再来」、消息流末尾 C2 卡（无 AI 角标、无付费入口）。

## 7. 响应式

- 桌面（PC 浏览器）为主场景：OJ 刷题与 Ctrl+V 粘贴都发生在 PC，讲题全程不离开当前窗口；移动端定位落地承接与碎片回看（NFR-USE-01/02）。
- 断点：<768px 移动单列；≥768px 桌面双栏（左栏历史 260px + 右栏会话）。
- 同一组件两断点同构：阶梯横条（紧凑/展开）、历史项（列表卡/侧栏行）仅密度差异，类名一致。
- 消息流列宽上限 640px 居中，代码卡横向可滚。

## 8. 无障碍

- 正文/背景对比度 ≥ 7:1（墨色 on 暖纸）；强调文本（赭石/竹绿/印章朱 on 纸底）≥ 4.5:1。
- 层级、盖章、变式状态均文字直书（「L2 关键步骤」「已听懂」「变式答错」），不单靠颜色传达。
- 印章动画非状态唯一载体：stamp-note 文案同步表达。
- 可点目标 ≥ 40px（解锁/发送/听懂按钮）。

## 11. 设计决策与交接事项（定稿前记录）

2026-11-11 交接补充：L1/L2 展示「正在准备讲解…」直到整轮答案边界检查通过；检查失败不先上屏再撤回。网络断开提示「连接中断，正在恢复已有讲解」，续传不显示新扣次；进程中断显示本轮未完成，由用户显式选择重试才创建新计费操作。生成失败维持原阶梯，不能出现未收到 L2 正文却显示已升到 L2 的状态。历史回看分别展示创建时所报级别和本次最终确认级别。

1. 历史列表「变式待复习」筛选是否进 P0：原型已给筛选 chip，若裁剪则隐藏该 chip，列表项状态标签保留。
2. 桌面端左栏是否默认展开：原型按展开呈现；窄桌面（768–1024px）可折叠为图标栏，实现期定。
3. 印章日期格式 `2026·10·26` 与中点分隔符为设计稿定稿样式，若本地化需要可调，不动双环结构。
