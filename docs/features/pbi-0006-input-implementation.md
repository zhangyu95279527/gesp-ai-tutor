# PBI-0006 PC统一输入基础切片

Status: approved
日期：2026-11-12；追溯FEAT-002 / PBI-0006。延续检查点先基础功能、后配置外部服务的约定。

## 已确认事实与实现边界

- 共用输入组件挂载于开发环境/session；生产沿用现有服务未开放边界。
- 同一题干框接收文本或剪贴板图片，文件选择无capture；只保留单一题目来源，切换来源先显式清除原输入，避免丢失用户内容。
- 题干10000字符、代码5000字符，字符按Unicode码点计算；图片10MiB（10485760字节），仅PNG/JPEG/WebP，空文件拒绝。浏览器解码失败显示重选建议；客户端校验不替代服务端字节检测。
- 文本去空白后少于10字符视为明显过短，这是可调整的基础校验假设，不代表已实现“非题目”语义检测。疑问点本轮不新增产品长度上限。
- 浏览器本地预览不标AI；不生成考点/级别，不称识别成功，不创建会话、不扣次。无localStorage持久化，不向服务传送内容；刷新即丢失。
- 附件object URL在替换、清除及卸载时释放。无图像直拍、假历史数据或假识别结果。
