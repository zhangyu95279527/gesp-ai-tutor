## 1. 范围与非范围

范围内：

- 首页「真题模考」入口卡（exam-banner）：首页既有分段入口（讲题/诊断）之外的独立挂载点。
- 套卷列表：按级别组织（chip-row 复用），默认选中所报级别；套卷卡标注来源（GESP 历届真题，CCF 主办）、时长、题量、完成状态。
- 开考确认：考试规则与判分参考性声明（PBI-0023 文案 AC 的 UI 承载）。
- 限时作答：全屏 exam-shell（双行顶栏：套卷名 + 倒计时 + 交卷 / 部分切换 sec-tabs + 当前部分题号导航三态）；客观题（选择/判断）单栏作答（opt-list），编程题左题右码（深墨 C++ 编辑器，语法高亮复用 --code-* token）。
- 交卷：未答完确认弹窗；倒计时耗尽自动交卷。
- 判分中（≤30 秒口径，NFR-PERF-04）与判分结果：总分 + 逐题 verdict；「判分不计入日限额」明示；错题归集提示。
- 逐题评测详情 + 讲评入口：按三部分逐块展开——客观题错题行（你的答案 / 正确答案）与编程题测试点表格；讲评消耗预告（每题计 1 次，客观题同口径）；讲评会话携带题目与作答上下文。

非范围：

- 讲评会话内部阶梯内容：复用 FEAT-002 讲题会话框架，本文仅定入口与上下文注入（C4）。
- 题库建设后台、测试数据校准流程（PBI-0023 主体为运营/工程任务，无用户可见面）。
- 断网本地暂存的恢复提示 UI：本期以开考确认页规则文案告知（a3），独立断网提示帧不设计。

## 3. 用户流

F1 模考主流（PBI-0024，PC 主场）：

```
首页 exam-banner → 套卷列表（默认所报级别）→ 开考确认（规则 + 判分声明）
→ 全屏作答（倒计时启动）→ 逐题作答/标记 → 交卷（未答完弹确认）→ 判分中 → 判分结果
```

F2 自动交卷分支（FR-EXA-02）：

```
倒计时耗尽 → 自动交卷提示（sys 性质）→ 判分中 → 判分结果
```

F3 讲评流（PBI-0026）：

```
判分结果 → 逐题「讲评本题 · 消耗 1 次」→ 讲评会话（注入题目 + 我的作答 + 评测结果）
→ 阶梯引导 L1 起（计 1 次，C1 刷新）
```

F4 错题归集（PBI-0025，后台触发 + 结果页提示）：

```
判分完成 → 未满分题即时归集错题本 → 结果页提示「5 道未满分题已加入错题本」
```

## 4. 信息架构与页面清单

挂载点：首页（exam-banner，新增）→ 模考模块三页（套卷列表 / 开考确认 / 作答全屏）→ 判分两页（判分中 / 结果）→ 讲评会话（复用会话页）。

贯穿案例：「2024 年 3 月 GESP C++ 三级真题」，官方 100 分制 27 题（题号连续 1–27）：一·选择题 15×2=30、二·判断题 10×2=20、三·编程题 2×25=50，限时 120 分钟（1–4 级档），合格线 60。学生作答结果：选择 26/30（错第 6 题循环执行次数，选 C 正确 B；第 12 题数组下标越界，选 A 正确 C）、判断 18/20（错第 19 题逻辑运算符优先级）、编程 15/50（第 26 题数字反转部分得分 15/25，过 3/5 测试点——与 FEAT-003 贯穿案例同源，负数边界丢分；第 27 题最短排队 WA 0/25）；总分 59/100，差 1 分未过合格线。5 道未满分题即时归集错题本（FEAT-008 接续）。C1 计数：进入模考时今日剩余 6；判分不计次全程保持 6；讲评发起计 1 次，6 → 5。

## 7. 响应式

- 桌面 1120 主场：exam-shell 左右分栏（题目 42% / 编辑器 58%）；套卷列表双列卡。
- 移动 390：套卷列表单列；判分结果浓缩（C5）；补充 M1/M2 作答帧，保持既有 NFR-USE-01 的两端完整可用。作答采用题面/作答标签切换，保留同一倒计时和答案，不要求移动端左右分栏；全屏是应用内沉浸布局，不依赖浏览器 Fullscreen API。编程区独立横向滚动、不使整页溢出，软键盘出现时仍可暂存与交卷。

## 8. 无障碍

移动补充帧：M1 题面/选题与 M2 编程编辑/本机暂存。原型为静态状态，不能代替真实语法高亮、暂存或交卷验证。离线到时只锁定答案并显示待提交，不声称服务端已收到；服务端以开考时确定的 deadline 判定时限，离线补交与超时恢复契约在 FEAT-007 技术设计中定稿，未完成前相关 AC 不算满足。

- verdict-chip / timer-pill 均文字直书（AC/WA/数字时间），不单靠颜色。
- q-nav 方块辅以形状差异（实底/描边/三角），非纯颜色编码。
- 倒计时耗尽自动交卷为系统行为，提示卡文字明示，无隐藏状态变更。
