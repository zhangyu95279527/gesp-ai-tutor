# 诊断三件套输入切片

2026-11-13；TASK-0027。复用FEAT-003定稿A1～A4布局与现有图片类型/大小/字节校验，不引入新架构。

- 三件套为题目文字或截图、评测结果文字或截图、非空代码。题目10～10000字符、评测描述1～2000字符、代码1～5000字符，前后端统一按Unicode字符计数。
- 题目与评测各自文字/图互斥。截图粘贴/文件选择最多一张，PNG/JPEG/WebP≤10MB、≤2000万像素且可解码；当前仅本地预览，不假装已上传或识别出WA。
- 代码可直接粘贴或显式导入UTF8文本文件（cpp/cc/cxx/c/h/hpp/txt）。非UTF8/含NUL/过大文件拒绝且保留原代码；导入5001字符会完整显示并阻止预览/提交，不自动截断。文件读取上限1MB是客户端资源保护，原文件不修改。
- 可手动声明评测状态（WA/TLE/RE/CE/AC/部分得分/未知）；明确是用户填写，不当作OCR识别结果。可声明自行裁剪代码，持续提示缺失上下文风险。
- PC两栏：左题目/评测、右代码通高；预览展示原始三件套，不调用模型、不扣次。当前页草稿在编辑/切换预览/失败时保留，刷新后不保证保存；不写浏览器持久存储。
- 后端DiagnosisInput拒绝缺项、额外字段与类型转换。ImageStore.read_owned按owner读取两个独立图片，调用现有validate_image验证真实字节，再分别做文本/图片安全检查；prepare只返回准备产物，无PG会话/额度/模型副作用。
- POST /api/dia/sessions要求登录、同源写保护、幂等键和有界JSON。未配置存储/安全/识别时503，绝不返回固定诊断或扣额度。真实成功入口由后续诊断任务装配。
- 页面沿用开发环境可用开关，入口加在讲题/历史导航。识别按钮在服务未开放时禁用；同页图文预览和输入校验仍可用。
