# PBI-0016 解决状态回填切片

TASK-0030；沿用定稿C3/C4与保留“改状态”的决定。本轮只做用户反馈，不生成修正答案、追问或变式。

- 用户可在回OJ自行验证后，对本人已完成且已检诊断回填solved/unresolved；不强制先使用尚未开放的修正阶梯。该状态是用户报告，不表示系统重新判题或证明诊断正确。
- GET/POST `/api/dia/sessions/{id}/resolution`复用认证、类型归属、no-store及写保护。不存在/外人/讲题记录404；未完成/失败/活动操作不得写入，损坏已保存结果503。
- 每条诊断有一个当前反馈状态/独立version/时间；没有回填时null/version0。反馈版本与诊断生成revision分离，不改变冻结文本、消息、操作或阶梯。
- POST严格只接受status和expected_version，需幂等键。按会话加锁，先核对本人再重放回执，同键变化冲突；新请求expected_version不匹配409。不同键重复同一状态且版本一致时不增版本、不增统计事件，但保存回执。
- 当前状态、幂等回执/改判留痕同事务保存；任何核心写失败回滚。改判保留原回执，旧键重放返回原回执；客户端成功后GET最新状态，避免将旧回执误当最终态。
- 不调用额度、模型或Judge。可从当前反馈表统计已回填数、已解决数、未解决数；解决率分母为已回填诊断，未回填单列，不能当未解决。改判按最终态，重试/同态不增加分母。ops事件仅辅助，回执与当前表为持久事实。
- PC系统卡不挂AI标识：未填显示“验证过了吗？”及“已解决/还没解决”，已填显示留痕章和“改状态”。保存不确定时不显示成功，重试保留同键/同负载，重新读取只GET；版本冲突刷新后让用户重新选择，不自动覆盖。
- 已解决显示禁用变式入口；未解决显示追问尚未开放及以后每次追问计1次说明。本轮不假装已经触发下一步。
- 0012_resolution无反馈数据时可往返，有任何当前反馈或回执时拒绝降级，不删除用户留痕。
- PBI-0016保持in-progress；修正阶梯及完整AC1/AC2追问/AC3变式不属于本轮验收。
