## 1. 范围与非范围

**范围内**：三源归集的两处手动入口留痕（讲题会话、诊断会话）；错题列表与考点/级别/来源/题型筛选；手动移除；三类重练作答（编程题评测机判分 / 选择判断客观题即时判分 / 讲题诊断源 AI 判读）；重练结果与首次对比；站内通知与每周邮件两个提醒通道及分别关闭的设置项。

**非范围**：模考判分过程（FEAT-007）；讲题/诊断会话本体（FEAT-002/003）；进步曲线图表化（J4 明确"最简：正确率对比数字"）；推送/订阅消息（Web 无此能力，O1 已定降级为站内 + 邮件）。

## 2. 设计语言复用与新增

**复用共享层**：tokens、帧结构、设备框、appbar/usage-pill、chip/chip-row（筛选）、mini-tag（级别/来源/题型）、verdict-chip（首次结果）、resolved-bar（归集/掌握留痕）、exam-banner（首页入口卡，自 FEAT-007 上移）、btn-line、modal-mask/modal-card（移除确认，自 FEAT-007 上移）、exam-code/code-editor（重练作答编辑器，自 FEAT-007 上移）、exam-q.wide/opt-list（客观题重练作答，自 FEAT-007 上移）、btn-primary、skel。

**本特性新增（内联）**：
- `.wb-stats` 列表页统计带（共 N 题 · 待重练 X · 本周归集 Y）
- `.wb-row` 错题行卡（row1：题名 + 级别/来源/题型章 + 首次结果章 + 操作；row2：考点 · 首次信息 · 重练状态）
- `.wb-filter-label` 筛选行分组小标（级别 / 考点 / 来源 / 题型）
- `.retake-note` 重练页计次说明丸（评测机判分不计次 / AI 判读计 1 次）
- `.answer-box` AI 判读重练的文本作答卡（静态高保真）
- `.compare-grid` 重练结果对比（首次卡 / 箭头 / 本次卡 + 进步数字）
- `.notice-row` 站内通知行（未读点 / 标题 / 时间）
- `.mail-card` 每周邮件样例卡（邮件头 + 内容摘要 + CTA）
- `.set-row` + `.switch` 提醒设置行与开关（on/off 两态）

## 3. 用户流

```
归集（三源）                浏览与筛选              重练                    提醒
模考判分 → 自动归集 ──┐
讲题会话 → 收入错题本 ─┼→ 错题本列表 → 筛选 → 重练作答 → 判分/AI判读 → 对比首次 → 已掌握
诊断会话 → 收入错题本 ─┘        ↑                                ↓
                          手动移除                    每周一 09:00 站内通知 + 邮件汇总（可分别关闭）
```

计数口径（BR-LMT-3）：浏览、筛选、移除、评测机判分与客观题即时判分的重练**均不计次**，usage-pill 全程 6 不变；仅 AI 判读重练计 1 次（C3：6 → 5，按钮直书消耗）。

## 8. 无障碍

- 首次结果不单靠颜色：verdict-chip 文字直书（AC/部分得分/WA）。
- switch 两态以位置 + 底色双重区分，不依赖颜色单通道。
- 未读通知：圆点 + 字重双通道。

## 11. 设计决策与交接事项（定稿前记录）

1. **讲题源错题的"首次结果"口径**：讲题收藏题无判分记录，列表首次结果列显示「—」。是否需要记录"讲中答错"作为首次基线？待 PO（当前按最简实现，J4 允许）。
2. **已掌握题的去留**：重练全对后保留在列表（标已掌握）还是自动移出？当前设计保留 + 状态章（C4），不移除——移除权交给用户（B2）。
3. **提醒触发阈值**：固定每周一 09:00 汇总，无"积压 N 题才提醒"阈值。待运营数据后再议。
4. **AI 判读计次口径**：C3 按"AI 判读 = AI 调用"计 1 次处理（BR-LMT-3 仅豁免非 AI 部分）。若 PO 决定豁免，C3 按钮副标改为"不计入日限额"。
