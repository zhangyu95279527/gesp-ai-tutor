这是完整实现。先整体读一遍，再看下面的逐行要点。

C++
// 数字之和 · 循环写法
      #include <iostream>

      int main() {
          int n, sum = 0;
          std::cin >> n;            // 读入正整数
          while (n > 0) {
              sum += n % 10;       // 取出个位，累加
              n /= 10;             // 去掉个位
          }
          std::cout << sum << std::endl;
          return 0;
      }
逐行要点

n % 10：取余拿到当前个位；n /= 10：整除去掉个位。两步一轮，直到 n 变成 0。

循环条件 n > 0：n 是 0 时直接输出 0，边界天然正确，不用特判。

时间复杂度 O(位数) ≈ O(log n) · 空间复杂度 O(1)
拓展视野 · 超出三级考纲

这题也能用递归一行写完：sum(n) = n%10 + sum(n/10)。递归要到四级才系统学习，现在了解即可，不要求掌握。

为什么 n % 10 拿到的是个位，而不是十位？
09:58 · 追问
追问 AI 生成

因为十进制里，一个数除以 10 的余数就是它的个位。比如 12345 = 1234 × 10 + 5，余出来的 5 正是最后一位。

而十位是「除以 10 之后」新数的个位——所以循环里每轮先 % 10 拿当前个位，再 / 10 把下一位挪到个位上，轮流取。

L3 · 完整讲解 AI 生成
C++
int n, sum = 0;
cin >> n;
while (n > 0) {    // 还剩数位就继续
    sum += n % 10;   // 取个位累加
    n /= 10;          // 去掉个位
}
cout << sum << endl;
时间复杂度 O(位数) ≈ O(log n) · 空间 O(1)
