# 诊断历史列表切片

TASK-0031；PBI-0011 AC2与PBI-0016 AC2的历史呈现支撑，沿用诊断UI C5与现有历史页面样式。

- `/history?type=diagnosis`展示本人已受理的诊断，列表项链接`/diagnosis?id=...`；讲题列表保持`/history`。增加讲题/诊断记录导航，不要求用户已知会话ID。
- GET `/api/dia/history`认证取owner，查询始终限制dia类型且存在diagnosis操作。未识别/未确认/额度拒绝的材料不属于已受理历史；已受理的待执行/运行/完成/失败/中断均可回看状态。
- 按诊断受理操作created_at、会话UUID倒序；时间固定，不随反馈改判重排。20条/页，最多50。搜索完整冻结题干的字面子串（最长100字符），可筛选all/solved/unresolved/unreported。
- 未回填仅指无反馈，与用户明确未解决分开。反馈取当前最终态；列表只返回题目摘要（最多100字符）、级别、状态、首选类别与最终反馈，不返回原图/代码/完整模型候选。
- 完成态通过已有结构/原文/检查记录校验才展示首选错因；损坏已保存结果拒绝整页读取，不伪造分类。未完成不携类别。读取中过期未落库操作投影为中断，不触发重跑。
- 游标含版本、owner、查询/筛选/页长、时间和UUID，严格验证长度/形状/时区及上下文匹配；游标只用于定位，不作授权凭据。所有SQL均使用登录owner，不信任游标扩大范围。
- keyset分页防重复，客户端追加时再次按ID去重；切换筛选清空旧页/旧游标。错误保留已有列表并可重新查询，不自动发POST。
- 页面区分类别AI标识、诊断进行状态、用户解决反馈；显示“未回填”而不暗示尚未解决。列表/详情/搜索/筛选/刷新均不扣次、不调用模型。
- 沿用生产页面关闭开关，无新迁移。停止条件为API隔离/分页/摘要与PC可达回看证据、完整回归和Git同步；完整修正/追问/变式及真实生成仍待后续。
