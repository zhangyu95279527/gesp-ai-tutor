## 1. 范围与非范围

范围内：

- 登录/注册流：邮箱输入、验证码发送/重发/错误/锁定、新邮箱自动注册（同一入口，无「注册/登录」分流）。
- 首次资料收集：昵称、出生年月、所报级别（1–8），缺项拦截；未成年分层（<14 周岁）监护人同意与条款展示。
- 设置页：资料展示、级别修改（次日生效提示）、协议版本留痕展示、账号注销（二次确认）。
- 体验模式：未登录首页体验入口、内置示例题选择、体验会话页变体（不计次口径的 UI 差异）、人机验证、注册墙。
- 体验转注册：结果页注册引导卡、注册完成回流与额度切换提示。

非范围：

- 获客落地页（PBI-0018 暂缓）、分享卡片（PBI-0017 暂缓）、邀请码门控（PBI-0004 暂缓）。
- 会话页本体、阶梯卡、变式卡：FEAT-002 设计范畴，本文仅定义体验模式下的差异槽位。
- 协议/条款正文内容：法务产物，本文仅定展示位与版本留痕呈现。

## 2. 设计语言复用与新增

全量复用 FEAT-002 第 2 节「讲义纸感 · 循循善诱」：纸底、墨色、indigo 主色、宋体标题、印章朱单语义。新增仅 3 个组件级定义：

| 组件 | 说明 |
|---|---|
| `.otp-row` 验证码分格 | 6 格等宽输入格，mono 字体数字；当前格 indigo 边框，已填格墨色数字，错误格 danger 边框 + 抖动一次（0.3s，仅错误反馈时刻） |
| `.id-card` 身份卡 | 设置页资料容器：paper-raised 卡面 + 宋体昵称 + mono 小号字段标签，行间发丝线分隔 |
| `.guest-chip` 体验章 | 顶栏 C1 槽位的体验态替代物：纸凹底 + ochre 描边胶囊，文案「体验模式」，非按钮 |

动效约束不变：全特性仅允许验证码错误抖动一处新动效（错误反馈语义），不引入其他动画。

## 3. 用户流

F1 验证码登录/注册主流（PBI-0001）：

```
输入邮箱 → 「获取验证码」→ 60s 重发倒计时 → 输入 6 位验证码（5 分钟有效）
→ 验证通过：新邮箱自动注册并登录 / 已注册邮箱直接登录 → 登录态 30 天
```

F2 异常分支：

```
验证码错误 → 行内提示剩余可试次数（共 5 次）→ 连续错 5 次锁定 10 分钟（输入区禁用 + 锁定提示）
未收到 → 60s 后重发；间隔内重复请求提示剩余等待秒数
```

F3 首次资料流（PBI-0002/0003，注册完成强制进入）：

```
昵称 → 出生年月 → 所报级别（1–8 picker）→ 按月粒度判断是否需监护同意
  14岁生日月的次月首日起：协议勾选行（用户协议 + 隐私政策）→ 完成
  此前（含生日月）：追加保护条款与监护同意；说明「仅收集出生年月，生日所在月仍需确认监护人同意」
缺任一项提交 → 行内拦截定位到缺项
```

F4 体验模式流（PBI-0012）：

```
未登录首页 → 粘贴题目体验 / 选内置示例题（移动端）→ 人机验证？（同 IP 当日第4次及以后发起）
→ 完整体验会话（L1–L3 + 追问 + 变式，整体计 1 次体验，会话内不再计次）
→ 结果页 → 转注册引导
当日再访 → 注册墙（不可再次发起）
```

F5 转注册流（PBI-0013）：

```
结果页注册引导卡 → 进入 F1 注册流（不丢失结果页上下文，注册完成回流）
→ 当日即按正式 15 次口径，已发生体验不抵扣 → 回流提示「已解锁正式额度」
```

F6 级别修改流（PBI-0002，BR-LVL-4）：

```
设置页修改级别 → 保存即提示「次日 0 点起新会话生效」→ 历史会话按当时级别保留展示
```

## 6. 组件状态表

### 6.1 验证码 `.otp-row`

| 状态 | 呈现 |
|---|---|
| 待输入 | 当前格 indigo 1.5px 边框，其余发丝线 |
| 已填 | 墨色 mono 数字 20px |
| 错误 | 整组 danger 边框 + 单次抖动；下方行内红字剩余次数 |
| 锁定 | 整组置灰禁用，行内提示「错误次数过多，已锁定 10 分钟」 |
| 过期 | 提交时行内提示「验证码已过期，请重新获取」，重发按钮恢复可用 |

### 6.2 重发按钮

常态文字按钮「重新获取」；倒计时中禁用 + 文案 `{s} 秒后可重发`；锁定期禁用。重发间隔 60s、锁定 10 分钟均为 FR-ACC-01 口径。

### 6.3 体验会话页差异（对 FEAT-002 的槽位覆盖）

| 槽位 | 注册态（FEAT-002 定稿） | 体验态（本文） |
|---|---|---|
| 顶栏右槽 | C1 用量指示器 | guest-chip「体验模式」（非按钮，点击无交互） |
| 解锁卡消耗预告 | `消耗 1 次 · 今日剩余 n → n-1` | 不渲染该行（体验会话整体计 1 次） |
| 变式提交消耗说明 | `生成时已计 1 次，本次提交不再扣次` | 不渲染 |
| 输入区占位 | `继续追问…` | `继续追问这道题（不单独扣体验次数）…` |
| 消息流末尾 | 变式结果卡收尾 | 变式结果卡 + 注册引导卡（D1） |

### 6.4 注册引导卡 `.signup-card`

paper-raised 卡面 + indigo 主按钮；价值清单三行（带图标）：每日 15 次完整额度 / 错因诊断 / 错题本。不使用印章朱（盖章语义专属）、无紧迫感文案（不发明「限时」话术，与 BR-LMT-5 无付费口径一致）。系统消息属性，不挂 AI 角标。

### 6.5 注册墙 `.guest-wall`

整页替换输入区（非模态）： ochre 图标 + 主文案 + 价值清单 + 主按钮 + 次文案。与 C2 超限卡形态区分：超限卡是会话内联消息，注册墙是体验入口页整态替换。

## 7. 响应式

- 登录/注册、onboarding：移动全宽；桌面居中 480px 卡 + 左侧品牌区（宋体标语 + 纸纹底），≥768px 生效。
- 设置页：移动单列堆叠；桌面左导航 200px + 右内容 640px。
- 体验模式页面与 FEAT-002 会话页断点行为完全一致（<768px 单列 / ≥768px 双栏）。

## 8. 无障碍

- otp-row 实现为 6 个独立 input，每格 `aria-label="验证码第 n 位"`；错误提示 `role="alert"` 即时播报。
- 未成年条款展开区与勾选框 `aria-expanded`/`aria-required` 关联；未勾选拦截焦点移至勾选行。
- 倒计时禁用按钮用 `aria-disabled`，不以颜色单通道表达禁用。
- 注册墙、注销模态焦点圈定；注销确认按钮需显式点击，不回车默认触发。
- 对比度沿用 FEAT-002 基线（正文 ≥7:1，强调 ≥4.5:1）；可点目标 ≥40px（移动端主按钮 44px）。

## 11. 设计决策与交接事项（定稿前记录）

2026-11-11 交接补充：资源保护拒绝与产品额度用尽分开显示。429 resource_rate_limited 提示「请求较频繁，请稍后重试」并按 retry_after 恢复；409 session_resource_exhausted 提示「本次体验已达到使用保护上限，已有讲解仍可回看」，不显示额外扣次或错误答题结论；默认保护值须由正常完整体验回归证明足够。注册价值清单按实际已上线功能显示，P2 未上线不承诺立即可用错题本。内测环境访问提示由 ADR-002 批准后接入，不把隐藏 URL 当门控。

1. 人机验证组件选型（滑块/点选/第三方）为技术选型项，原型以滑块占位，实现期由技术设计定稿。
