# ADR-002 — 内测部署访问边界替代产品邀请码

## Status
draft

日期：2026-11-11。提交 GB 人工评审；不代表已批准或已实施。

## Context

- Backlog 已暂缓 PBI-0004 邀请码，不重开该产品范围决定。
- PRD O9 与 GA 基线要求内测不面向公众，基线具体机制仍为邀请码。
- 隐藏入口不能执行该约束，公开 API 仍可绕过页面注册或调用模型。

## Decision

提议使用现有 nginx 的 HTTPS Basic Auth 对整套内测环境设置独立访问边界；为每名受邀测试者签发可撤销凭证，不新增产品邀请码功能或外部服务。

账号验证、体验额度和监护人同意仍按现有产品流程执行。基础设施访问凭证不等于产品注册，不替代产品用户权限。

## Options considered

| 方案 | 意见 |
|---|---|
| 隐藏入口/noindex | 不采用，不形成访问限制 |
| 恢复产品邀请码 | 不作为默认，改变已暂缓范围 |
| 现有 nginx 受邀访问凭证 | 提议采用，需验证所有入口均在边界内 |

## Consequences

- 受邀用户先过环境访问验证，再选择匿名体验或产品登录；增加一次内测环境进入步骤，属于邀请准备阶段，不计为产品注册。
- 保护 web/API/SSR/静态资源/beacon/上传签名入口；容器端口仅内网开放，CDN 内测不缓存受控内容。
- 每人独立凭证、可单独撤销；配置只存密码哈希，秘密不进仓、不放 URL/query、不写日志。服务间调用仅从受控内网访问，禁止公网路径免鉴权例外。
- OSS 签名 URL 仍为本人短时效访问，不将公开对象地址作为门控替代；禁止把 Basic Auth 凭证传给对象存储/模型厂商。
- 验证：未授权 web/API/静态资源拒绝；转发 URL 不获授权；注销环境凭证后无法再次访问；直连容器端口拒绝；产品账号不能访问他人会话。
- 在 GB go 前保持此方案为提案；内测发布条件未满足。批准后在同一变更中同步 PRD FR-ACC-08/NFR-CMP-01/范围说明与架构基线，保留邀请码暂缓记录。

## Affected components/repositories

- gesp-tutor-api：nginx/Compose 部署、端口与网络配置、运维凭证撤销流程。
- gesp-tutor-web：内测访问说明，不新增邀请码页。
- gesp-ai-tutor：PRD/基线/FEAT-001/内测发布验证记录。
